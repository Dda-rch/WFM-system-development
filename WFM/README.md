# WFM-система для розничной сети — User Story Map и карта экранов

## О проекте

Учебный проект по бизнес-анализу: разработка требований к WFM-системе (Workforce Management) для розничной сети магазинов. Система должна закрывать три сценария:

- **веб-интерфейс для директора магазина** — контроль смен и загрузки сотрудников на точке;
- **веб-интерфейс для HR-директора** — управление персоналом и аналитика по сети магазинов;
- **мобильное приложение для сотрудника** — просмотр графика, обмен сменами, учёт рабочего времени.

Требования собирались по итогам интервью с заказчиком (Максим Павлов), проведённого на семинаре курса, и последующих уточняющих вопросов в чате курса.

## Задача 1. User Story Map

По итогам интервью с заказчиком были выделены роли, их цели и последовательность действий в системе. На основе этого построена **User Story Map**:

- backbone (основные этапы работы пользователя с системой);
- пользовательские активности внутри каждого этапа;
- пользовательские истории (user stories) с приоритизацией по релизам (MVP → следующие итерации).

## Задача 2. Карта экранов

Спроектирована карта экранов продукта: разделена на десктопную часть (директор магазина, HR-директор) и мобильную часть (сотрудник). Карта показывает состав экранов, переходы между ними и то, какой сценарий пользователя они закрывают.

 **Miro-доска (карта экранов):** https://miro.com/app/board/uXjVJG2sH64=/?share_link_id=853998891854

 ## Дополнительная задача. BPMN-схема процесса обмена сменами

 Дополнительно смоделирован в нотации BPMN 2.0 один из ключевых процессов системы — обмен сменами между сотрудниками: от создания запроса инициатором до согласования директором магазина и обновления графика.
